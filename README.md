# semicon-study

반도체 공정·계측(DMI: Defect & Metrology Inspection) 면접 준비를 위한 7주(2026-09-24 ~ 2026-11-11) 일일 학습 기록.

- `index.html` — 49일을 7×7 웨이퍼 맵으로 표시한 진행 현황. 브라우저에서 바로 열면 된다(외부 네트워크·라이브러리 없음)
- `days/YYYY-MM-DD.html` — 날짜별 기록. 핵심 메시지, 학습 내용(개념 SVG 포함), 점검 질문·모범답안, 예상 꼬리질문, 용어, 다음 예고. 우상단 버튼으로 읽기/퀴즈 모드 전환
- `curriculum.md` — 7주 커리큘럼
- `assets/` — 공통 스타일·스크립트

개인 맥락 파일(`CLAUDE.md`, `progress.md`)과 `seed/` 원본은 로컬에만 두고 커밋하지 않는다.
